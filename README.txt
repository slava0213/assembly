КОНФИГУРАТОР ПК — прототип
==========================

Структура:
- index.html       — главная страница
- css/style.css    — стили
- js/data.js       — база комплектующих
- js/app.js        — логика

Запуск:
1. Откройте файл index.html двойным кликом в браузере.
2. Выберите класс сборки, затем последовательно
   подбирайте комплектующие.
3. Несовместимые варианты будут недоступны (затемнены).
4. В конце — итоговая смета. Кнопка «Скачать смету (PDF)»
   открывает системный диалог печати — выберите
   «Сохранить как PDF».

Примечание:
Цены ориентировочные и зашиты в js/data.js.
Чтобы обновить цены — откройте data.js текстовым
редактором и измените поле "price".
